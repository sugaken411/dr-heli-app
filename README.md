# 🚁 AW109 EMS System

航空医療・ドクターヘリ運用のための総合DXプラットフォーム。
現場でのオフライン入力、電子カルテへの転記、デブリーフィング、そして多職種での事案振り返りをシームレスに連携します。

各画面は個別にバージョン管理されており、共通のバックエンド（GAS）・データベース（Spreadsheet）に接続しています。バージョンは各画面右上のバッジで確認できます（例：index/search v14.12、admin/summary v14.0、checklist v13.0）。

## 🌟 全画面共通の基盤機能
* **インテリジェントローダー:** 現場の不安定な電波環境に対応するため、5秒で電波警告、15秒でタイムアウト・リロードを指示するローダーを全11画面に搭載。
* **通信エラー監視の最適化:** iOS PWA特有の電波瞬断時に発生する無害な `Load failed` および `Failed to fetch` エラーを検知してGASへの自動送信から除外する高精度フィルターを全画面に標準化。
* **日付フォーマットのパディング正規化:** スプレッドシート上の `YYYY/M/D` 形式とHTML5側の `YYYY-MM-DD` 形式の表記揺れを吸収する `normalizeDate` ロジックを、検索・カレンダー連携が絡む画面（library.html / report.html / management.html）に実装。
* **マスター管理CRUD機能:** 管理コンソール（admin.html）から、スプレッドシートを直接開くことなく「お知らせ」「取扱説明書」「Q&A」の完全な追加・修正・削除（CRUD）操作が可能。
* **多次元動的クロス分析（BI）:** 統計画面（summary.html）にて、縦軸・横軸をユーザーが自由に選択して再計算できる「Pivotヒートマップ」および「動的カスタマイズレーダー」を搭載。

## 📂 アプリケーション構成
1. `portal.html` (v13.1) - 全アプリの玄関口（未完了アラート・お知らせ・マニュアル表示）
2. `index.html` (v14.12) - 症例登録アプリ（現場入力用：移動用酸素・呼吸器の段組みUI、エコー・ベニューラ階層化対応）
3. `search.html` (v14.12) - 事案検索コンソール（カルテ完了処理・データ修正・CSV出力）
4. `management.html` (v1.4) - 統括・業務管理（月間カレンダー・出動状況および待機理由一覧）
5. `report.html` (v11.6) - 業務日報（浜町日誌・タイムライン自動生成・印刷・太陽位置連動計算）
6. `checklist.html` (v13.0) - 統合チェックリスト（日常点検入力・履歴および判定管理）
7. `debriefing.html` (v11.16) - デブリーフィング（多職種振り返り・疾患および病態評価入力）
8. `debrief_search.html` (v12.8) - 教育・事案検索（過去事例の学習用・クロス検索アーカイブ）
9. `library.html` (v13.2) - 資料集・アーカイブ（外部資料データベースへの接続）
10. `admin.html` (v14.0) - マスター管理コンソール（各種マスタ追加・Q&A回答・CRUD制御機能）
11. `summary.html` (v14.0) - JSAMSレジストリ・BIダッシュボード（Pivotヒートマップ・動的レーダーチャートによる多次元統計分析）

## ⚙️ 技術仕様・連携
* **バックエンド:** Google Apps Script (GAS) Webアプリケーション（単一doPost構成、`action`パラメータで処理を振り分け）
* **データベース:** Google Spreadsheet（1行目ヘッダー文字列完全一致による動的インデックスマッピング制御）
* **フロントエンド:** HTML5 / CSS3 / Vanilla JavaScript。外部ライブラリは画面ごとに必要なものだけ選択導入（Tailwind CSSは`management.html`・`report.html`のみ、Chart.jsは`management.html`・`summary.html`のみ、SunCalcは`report.html`の日の出没計算のみ）
* **PWA対応:** `manifest.json` と `sw.js` により、iPad/スマートフォンでのスタンドアロン起動に対応。`sw.js`はネットワーク優先方式（オンライン時は常に最新を取得し、通信失敗時のみキャッシュへフォールバック）。

## ⚠️ 既知のメンテナンス課題
* `manifest.json` の `name` が `v13.0` のまま固定されており、実際の各画面バージョン（最大 v14.12）と乖離している。更新時は合わせて見直すことを推奨。
